# Alarm Clock

A simple desktop alarm clock built with Python and Tkinter.

This project allows users to set an alarm by selecting the hour, minute, and second from drop-down menus. The application continuously checks the current system time and plays an alarm sound when the selected time is reached.

## Features

- Simple graphical user interface built with Tkinter
- Select hour, minute, and second
- Background time monitoring using threading
- Plays an alarm sound when the alarm time is reached
- Easy to understand project structure

## Technologies

- Python
- Tkinter
- datetime
- threading
- winsound
